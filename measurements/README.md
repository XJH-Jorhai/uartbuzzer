# Project measurements

These CSV files are the project's own measurements of the buzzer used for the
M2 fit, released under the project MIT license. They contain numerical sweep and
DCR readings, not songs or microphone recordings.

| File | Original acquisition |
|---|---|
| wide.csv | 2026-10-28 19:25:55 wide impedance sweep |
| fine.csv | 2026-10-28 20:23:06 fine resonance sweep |
| dcr.csv | 2026-10-28 20:22:16 repeated DC resistance |

Column names and numeric values are preserved. Historical timestamped copies
remain local in `results/th2851/`; no original local files were moved.
