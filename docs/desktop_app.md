# UART Audio Studio 1.4.1

导入 WAV 或文件夹，选择歌曲并连接对应串口后播放。默认单曲播放，播完停止；可显式选择顺序、循环或随机。整数或浮点 PCM WAV、中文路径、每首最长 10 分钟。设置实时音量或静音不会删除原始 WAV。

默认 B0；Beam 快速档与高质量档为可选编码器。Beam 首次运行包含 JIT 开销，转换可取消。模型估计线圈电流，不能据此声称校准声压或任意器件听感改善。预算耗尽或依赖不可用会保留安全回退；发布自检要求完整原生 TopW 搜索。

录音校准须由用户主动操作。单曲校准与录音时的歌曲内容、基础配置及负载模型绑定；替换歌曲内容或模型后不会误用于其他歌曲。保留手动导入全局配置入口。可选预失真是受限实验参数，不能视为跨歌曲通用校正。

默认数据目录为 `%LOCALAPPDATA%\ZipLab\UART Audio Studio`，保存歌单、设置、录音和长期转换结果。界面可打开该目录。移除列表引用不会删除原 WAV；移动文件后使用重新定位。算法或配置变化可能使旧转换指纹失效，首次需重新转换；旧文件不主动清理。不要把自己的数据目录加入源码或发布包。

源码运行、测试、构建命令见根 README。便携构建的 Qt/PySide6 动态库位于 `_internal`，可按兼容 ABI 替换；完整许可和上游源码链接在 `LICENSES` 中。单文件与便携构建都使用同一份 DSP 代码；构建清单记录依赖、选择器辅助函数 SHA 与各源文件 SHA，不承诺跨机器二进制可复现。

离线 EXE 自检（结果必须位于新建隔离目录）：

```powershell
New-Item -ItemType Directory qa-run
.\UARTAudioStudio.exe --self-test qa-run/selftest.json
```

自检生成原创合成音频，不接触串口、麦克风或真实歌单；检查两种波特率、两个 Beam 档位、磁盘缓存和预失真路径。
