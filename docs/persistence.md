# 歌单和长期转换文件

默认目录：`%LOCALAPPDATA%\ZipLab\UART Audio Studio`。文件库底部显示实际路径并提供打开目录按钮。

- `library.json`：原 WAV 路径、歌单、最后歌曲、转换文件关联。
- `library.json.bak`：最近有效备份；主文件失败时恢复备份，均损坏则禁止空歌单覆盖并显示提示。
- `prepared_audio/<指纹>.npz`：处理后 PCM、解算数据、UART 字节与分段时间表，长期保留，不被临时缓存淘汰。
- `cache/conversions/`：旧版临时缓存，命中时迁移。
- `settings.ini`、`sessions/`：本机设置和录音，不提交 Git。

同一音频、同一配置与算法版本直接加载结果，不重新补偿或编码；修改内容、波特率或处理配置生成对应新结果。原 WAV 仍须可访问，移动后请右键重新定位。NPZ 是数据容器，不能将整个文件原样发给串口。

默认“单曲播放 · 播完停止”；列表循环需显式选择。单实例保护避免两个播放器相互覆盖歌单。
