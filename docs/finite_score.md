# 离散曲谱（主旋律）· 1.5.0 预览

这是可选的离线编码器；新数据目录仍默认 B0，Beam 继续可用。先导入
WAV，再选择“离散曲谱（主旋律）”。它把原音频转成有限音高、有限力度
和离散时值的单声部事件，不能保证从混音分离主唱或乐器。

点击“曲谱 / 器件档案 / 特性测试”查看字典和音符事件，设置最多音高数
（默认12）、自动字典、时间量化（默认20ms）和可选八度适配（默认关）。
前端分析音区固定 MIDI48–96、10ms hop；扩大器件档案的范围不会扩大
扒谱音区。器件最小时值进一步约束起止，结果不是任意录音的精确音符边界。

| 显示项 | 含义 |
|---|---|
| 筛选候选权重覆盖 | 清理低支持候选后，有限字典覆盖的权重比例 |
| 原主线时长覆盖 | 相对前端自身选定旋律、在允许偏差内被谱事件表示的时长比例 |
| 未表示 / 待确认 | 范围、量化或器件约束造成的遗漏，不等同于原音乐真实休止 |
| 全局移调、实际偏移 | 明确记录对原输入音高的改动，八度适配不算原音高还原 |

这些覆盖值不是有真实标注的准确率。混音可能跟随伴奏；缺失基音可能高
八度；连续重复同音或连奏重击可能合并。算法分只是证据，不能当校准概率。
仅主旋律，保留这些负例。JSON 保存完整 Hz、力度、事件、休止和来源版本；
MIDI 将 Hz 近似为整数半音、起止近似到 tick，细节请保留 JSON。

命名器件档案可导入、导出，点击“应用选择”后才影响当前转换。默认“未测
平坦”只声明手动能力范围。相对实测、手动估计和电流代理有明确类别；
M2 线圈电流不是 SPL，未测及电流代理不作为声学增益奖励。低可信测量点
不参与声学补偿；gain×velocity 只是线性近似，不保证听感或声压改善。

曲谱分析使用旧均衡和400Hz高通之前的原始单声道16k PCM，旁路旧FIR
和本曲录音校准，旧校准记录仍保留。缓存绑定输入、前端/拟合版本、设置、
档案内容、渲染器、后端及音量。离线播放使用固定音量；改变音量后重新
编码，静音和0%实际停发。UART休止为停止写入、线路空闲，不能把拼接
BIN 当作原波特率连续载荷；导出必须保留分段时刻和 TransportPlan。
OS队列排空后等待休止，物理USB/FIFO时序未实测。

通用档案可以只导出曲谱，播放入口禁用。当前不生成步进电机运动命令；
未来后端仍需各自的控制映射、器件约束与实测。

“播放器特性测试”与“本曲录音校准”分开。先断开主窗口串口并关闭麦克风，
选好串口、麦克风、音高范围（最多24点）、两档参考音量、时长和摆位说明，
再点击“开始播放并采集”。启动、导入或打开设置均不会自动开设备。
测试背景、短音和间隔，记录基音/谐波、噪声、削波、起尾和采集状态；
最大谱峰不能冒充基音。可取消并回收专用设备，失败记录保留。

完成后审阅有效/失效点，确认保存新的档案，再显式选择使用。旧档案、
全局FIR及本曲校准不会被覆盖。位置、增益或硬件改变后应重新测试；
当前只在实测参考音量、baud、密度bias/amplitude和渲染器版本全部一致时使用响应权重；参数变化仍可使用能力范围但停用声学响应。
本预览的软件验收仅用模拟采集，真实声学测试需要用户主动开始。

预览包在独立目录交付，不替换1.4.1。离线包自检需要新的隔离数据目录：

```powershell
.\UARTAudioStudio.exe --data-dir qa-score-new --score-self-test qa-score-new/report.json
```

自检使用原创合成音符，检查曲谱、缓存重开和导出，不打开串口或麦克风。
不要把自己的音乐、派生曲谱、录音或特性测试证据放进公共源码。
